# Demonstration menu photographs

These local JPEG assets illustrate synthetic development menu entries.

- `buckwheat.jpg` derives from the existing Penpot `food-buckwheat` fill.
- `syrniki.jpg` derives from Penpot shape `743010df-21c5-8099-8008-d4732bfae36c`.
- `borscht.jpg`, `chicken-cutlet.jpg`, `vegetable-salad.jpg` and `berry-mors.jpg` were generated
  with the built-in image generation tool on 8 November 2026. The visual brief specified
  cream backgrounds, white dishes, soft daylight and recognizable cafeteria food.

All files have a maximum edge of 640 pixels and JPEG quality 82. Together they are about
529 KB. The original Penpot PNG and generated originals are retained separately. Real menu
operators can supply their own image URLs through the existing Menu API or admin interface.
Provisioning fills missing images and migrates the old demo buckwheat URL. Existing custom
image URLs and operator-edited item fields are preserved.
